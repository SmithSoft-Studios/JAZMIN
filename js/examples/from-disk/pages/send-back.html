Send a record back: a store inspection, written on this device

Harbour & Co.'s area managers inspect their stores with a phone, often where there is no signal. The page writes each inspection, with its photo, into a small .jzm in the browser, locked with the manager's submission key. Nothing is uploaded until it is sent; the owner files it into the shared file.

What this shows

The shared file opened with the Durban manager's access key, for the submission key it holds (reader.submissionKey). A form whose record (and photo) JazminBrowser.createWriter writes into a file locked with that key, checked here and offered for download. Then how the owner files it with the filing-service sample (fileSubmission).

The owner files it

Only the owner's key can change the shared file. The filing service checks that the sender still has a grant, opens the file with the sender's submission key (so a file made without opening the shared file is refused), checks the photo's first bytes and size, and appends the record into the sender's own branch. To try it on this computer, save the file into filing/inbox beside these pages, then in a terminal, in the JAZMIN folder's js folder:

The first command files every batch in the inbox (fileSubmission(), in examples/filing-service) and moves it to filed/, or to rejected/ with the reason. The second makes the shared file into a script again, so this page shows the new record after a reload. For this demo only, the owner key is in filing/owner.key; a real one stays on the machine that files the records.

On the device

const shared = await JazminBrowser.open(bytes, { key: accessKey });
const writer = await JazminBrowser.createWriter({ columns, key: shared.submissionKey });
await writer.writeRows([{ id, branch, area, rating, note, attachments: [`${id}/photo.jpg`] }]);
await writer.addFile({ path: `${id}/photo.jpg`, content: photo });
const blob = await writer.finish();   // keep it, send it when online

At the owner

fileSubmission('inspections.jzm', upload, { key: owner, keyId });
// { sender, filed: 1, updated: 0, duplicates: 0, files: 1, ignoredColumns: [] }
