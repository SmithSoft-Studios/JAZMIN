Masked columns: a password as well as the key

payroll-masked.jzm is Harbour & Co.'s payroll for October, shared with a payroll clerk's access key. The key sees every row, but each person's email, bank account and ID number, and the directors' salaries, show masked until the clerk also gives the lock's password.

What this shows

A table as one key sees it, masked; the same table once the lock is open, each value revealed for a few seconds; and the file's CSV and JSON exported masked and with revealed values, side by side, with timings.

    How the file was written, and exported
    
      
    
        
    
          
    Writing (Node, the owner key)
    
          
    write('payroll-masked.jzm', payroll, { key: owner,
  columns: [
    { name: 'staff', type: 'string' }, { name: 'name', type: 'string' }, …,
    { name: 'email', type: 'string', mask: { lock: 'payroll', show: { keepFormat: true } } },
    { name: 'account', type: 'string', mask: { lock: 'payroll', show: { keepFormat: true, last: 4 } } },
    { name: 'id_number', type: 'string', mask: { lock: 'payroll', show: { first: 2, last: 2 } } },
    { name: 'salary', type: 'decimal', mask: { lock: 'payroll', rows: { grade: 'Director' } } },
  ],
  access: { grants: [{ key: clerk, rows: '*', columns: '*' }] },
  locks: { payroll: { password } },
  package: { masks: {                     // how viewers show revealed values
    salary: { reveal: 'value', seconds: 15 },
    id_number: { seconds: 10, export: false },   // never exported revealed by viewers
  } },
});
    
        
    
        
    
          
    Reading (this page, the clerk's key)
    
          
    const reader = await JazminBrowser.open(bytes, { key });
await reader.masked();   // [{ column: 'email', lock: { id: 'payroll',
                         //   unlocked: false }, shown: 'email_shown', at: 4 }, …]
await reader.unlock('payroll', { password });

// Exports: one column each, as viewers show them
await JazminBrowser.toCSV(reader, { revealMasked: false });
await JazminBrowser.toCSV(reader, { revealMasked: ['email', 'account', 'salary'] });
await JazminBrowser.toJSON(reader, { revealMasked: true });  // every unlocked column
await JazminBrowser.toCSV(reader, { masked: 'raw' });        // the columns as stored
    
          
    In Node it is the same: exportString(reader, 'csv', { revealMasked: false }). In
            .NET, reader.ExportView(filter, options, revealMasked) gives the columns and rows for
            CsvFormat.Write and JsonFormat.Write.
