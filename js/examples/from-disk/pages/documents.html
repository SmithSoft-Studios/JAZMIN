Documents: pages that travel with their data

A .jzm can carry a page, its styles and scripts next to the rows. The viewer shows the page in a sandbox: it reads the data, prints, saves a PDF, and can even save changes, but never sees the key or the network.

What this shows

Four documents, each stored in its file with the data: a report that saves itself as a PDF, a task list that saves changes, a dashboard that needs the internet, and a client file of four pages shown as tabs. Each lists its own scripts and styles (package.files), so the viewer's Files tab shows only the files people want.

Feature: documents (embedded files with a page) and document pages · USER-GUIDE §19.3, §19.5, §19.7 and §24.1

A print-ready report

Half a year of sales across five branches, drawn by the page inside report.jzm: totals, two charts and a table. Print it, or save it as an A4 PDF: the file says how.

  • Open to anyone: no password
  • Its saved shape Revenue by branch is under Export ▾ in the data tab
  • Two tables: the sales, and each branch's target, which the page reads by name

A task list that saves changes

The page inside tasks.jzm lets you edit, add and remove tasks. The file says which columns may change; the viewer checks that, shows you the changes, and saves them as a small change file.

  • Encrypted: the password is demo
  • The list's owner applies change files; rows changed by someone else meanwhile are held, not overwritten

A dashboard from the internet

The page inside dashboard.jzm uses the Inter font from Google Fonts, and Chart.js and icons from jsDelivr. The file says it needs to be online, so the viewer says so, and offline waits for the network instead of showing half a page.

  • Needs to be online: online: 'required'
  • Chart.js at an exact version, with an integrity hash: a changed file is refused
  • Without the charts, the page shows the figures as a table

A client file in four pages

The bank's clients and their transactions, with a document of four pages that the viewer shows as tabs: Clients, Transactions, a Summary with charts, and a Statement laid out for A4.

  • Encrypted: the password is demo
  • Each list page reads its own table and offers no Print; the Statement prints and saves a PDF
  • Only the Summary needs the internet (Chart.js, pinned, with its integrity hash): offline, the other tabs still work
  • Its script and stylesheet are its own files: the Files tab leaves them out

How they are made

The report

write('report.jzm', { sales, targets }, {   // two tables: the page reads both
  tables: [{ name: 'sales', columns }, { name: 'targets', columns: targetColumns, sortedBy: ['branch'] }],
  files: [
    { path: 'index.html', file: 'report/index.html' },
    { path: 'report.css', file: 'report/report.css' },
    { path: 'report.js', file: 'report/report.js' },
  ],
  package: { entry: 'index.html', pdf: { format: 'A4' },
    files: ['report.css', 'report.js', 'pdf.js'] },   // its own files: kept out of the Files tab
});
// report.js: const rows = jazmin.rows();   // its own table, sales
//            const targets = await jazmin.query({}, { table: 'targets' });   // another, by name
//            … jazmin.print();

The task list, and its owner

write('tasks.jzm', rows, { columns, files, password,
  package: { entry: 'index.html',
    edit: { key: ['id'], columns: ['task', 'owner', 'due',
      'status', 'priority'], add: true, delete: true } } });
// tasks.js: await jazmin.saveChanges({ update, add, delete });

// The owner, with a change file someone sent back:
applyChanges('tasks.jzm', changeFile, { password });
// { updated: 2, added: 1, deleted: 0, conflicts: [], … }

The client file: pages as tabs

write('client-file.jzm', { clients, transactions }, { tables, password, files,
  package: {
    pages: [
      { path: 'clients.html', title: 'Clients', table: 'clients', actions: { print: false } },
      { path: 'transactions.html', title: 'Transactions', table: 'transactions', actions: { print: false } },
      { path: 'summary.html', title: 'Summary', online: 'required' },     // Chart.js from jsDelivr
      { path: 'statement.html', title: 'Statement', table: 'transactions', pdf: { format: 'A4' } },
    ],
    files: ['app.js', 'app.css'],                 // the pages' own files: not in the Files tab
    allowedOrigins: ['https://cdn.jsdelivr.net'],
  } });
