Open a JAZMIN file

Choose a .jzm file on this computer. It opens in the viewer, read straight from disk: nothing is uploaded, and large files are fine, because only the parts needed are read.

What this shows

A start page that asks for any .jzm (Browse, or drop it), then hands it to the viewer, which reads only the parts it needs. For the demo file, Try buttons send filters that the file's indexes answer; Newest 20 reads the latest matches last first (reverse: true) against counting and reading the last page, and What will this read? says what a filter costs before it runs.
