# JAZMIN backlog

Work is split into small, independently shippable tasks. Each task lists:

- its **acceptance test**: what must pass before it is done;
- whether it changes the **format**: if so, it needs an RFC update, usually a
  reader or writer feature, and new interop fixtures (see
  [CONTRIBUTING.md](CONTRIBUTING.md)).

Format 1.0 ([design note](design/format-1.0.md)) replaced the pre-release
drafts. Format numbers 1.1–1.3 below refer to those drafts.

Status: ✅ done · 🔶 partly done · 🔜 next · ⬜ later
